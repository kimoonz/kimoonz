# 3. 액션과 데이터 처리

## 3.1 커넥터 등급

| 등급 | 예시 | 라이선스 |
| --- | --- | --- |
| 표준 | SharePoint, Outlook, Teams, OneDrive, Excel Online, Planner | Microsoft 365 포함 |
| 프리미엄 | **HTTP**, SQL Server, Dataverse, Salesforce, Azure 서비스 | Power Automate Premium/Process 필요 |
| 사용자 지정 | 사내 API를 OpenAPI로 등록 | 프리미엄 |
| 온프레미스 데이터 게이트웨이 | 사내 SQL, 파일 서버 | 프리미엄 |

액션 이름 옆의 다이아몬드(◆) 표시가 프리미엄입니다. 만들 때는 되는데
다른 사용자가 실행하면 라이선스 오류가 나는 경우가 여기서 나옵니다.

## 3.2 데이터 작업(Data Operations)

`각각에 적용` 반복을 없애 주는 핵심 액션들입니다. 성능 차이가 매우 큽니다(7장).

### 작성(Compose)

값 하나를 계산해 이름 붙여 두는 액션. 디버깅용으로도 최고입니다.

```
작성 (이름: 정규화된_사번)
입력: @{toUpper(trim(triggerBody()?['empNo']))}
```

- 표현식이 길어지면 중간 결과를 `작성`으로 쪼개세요. 실행 기록에서 단계별로 값이 보입니다.
- **병렬 분기 안에서는 변수 대신 `작성`을 쓰세요.** 변수는 공유 상태라 경합이 납니다.

### JSON 구문 분석(Parse JSON)

문자열 JSON에 스키마를 입혀 동적 콘텐츠로 노출합니다.

1. **샘플 페이로드에서 생성** 클릭
2. 실제 응답 JSON을 붙여넣기 → 스키마 자동 생성

> **필수 조정**: 자동 생성 스키마는 값이 `null`이면 실패합니다.
> 비어 있을 수 있는 필드는 `"type": ["string", "null"]` 로 고치고,
> 안 쓰는 필드는 `required` 배열에서 빼세요. 실무에서 가장 자주 터지는 액션입니다.

### 선택(Select) — 배열 변환

배열의 각 항목을 원하는 모양으로 바꿉니다. 반복문이 필요 없습니다.

```
시작: @{body('항목_가져오기')?['value']}
맵:
  사번   →  @{item()?['EmpNo']}
  이름   →  @{item()?['Title']}
  부서   →  @{item()?['Dept']?['Value']}
```

### 배열 필터링(Filter array)

```
시작: @{body('항목_가져오기')?['value']}
조건: @{item()?['Status']}  is equal to  승인
```

복잡한 조건은 **고급 모드**로 전환해 표현식을 직접 씁니다.

```
@and(equals(item()?['Status'], '승인'), greater(int(item()?['Amount']), 1000000))
```

### 조인(Join)

배열을 구분자로 이어 붙여 문자열로 만듭니다. 메일 본문 만들 때 유용합니다.

### CSV 테이블 만들기 / HTML 테이블 만들기

배열을 표로 만듭니다. HTML 테이블은 메일 본문에 바로 넣을 수 있습니다.
(스타일이 필요하면 결과 문자열을 `replace()`로 가공하거나 직접 HTML을 조립하세요.)

## 3.3 변수(Variables)

| 액션 | 용도 |
| --- | --- |
| 변수 초기화 | 트리거 바로 다음, 최상위 레벨에서만 가능 |
| 변수 설정 | 값 덮어쓰기 |
| 변수 증가/감소 | 숫자 카운터 |
| 배열 변수에 추가 | 배열에 항목 추가 |
| 문자열 변수에 추가 | 문자열 이어 붙이기 |

**변수 대신 `작성`을 쓸 때**

| 상황 | 권장 |
| --- | --- |
| 값이 한 번 정해지고 안 바뀜 | `작성` |
| 반복 안에서 누적해야 함 | 변수 (단, 아래 주의) |
| **병렬 분기 / 동시성 켠 반복 안** | ⚠️ 변수 금지 — `선택`+`조인` 같은 무상태 방식으로 |

> `각각에 적용` 안에서 변수에 값을 누적하면서 동시성을 켜면 값이 뒤섞이거나 누락됩니다.
> 반드시 동시성을 1로 두거나, 애초에 변수를 쓰지 마세요.

## 3.4 OData 쿼리 — 서버에서 걸러오기

가져온 뒤 `배열 필터링`으로 거르는 것보다, **처음부터 필요한 것만 가져오는** 편이 훨씬 빠릅니다.

`SharePoint - 항목 가져오기` 고급 옵션:

| 항목 | 예시 | 효과 |
| --- | --- | --- |
| 필터 쿼리 | `Status eq '승인' and Amount gt 1000000` | 서버에서 필터 |
| 정렬 기준 | `Created desc` | 서버에서 정렬 |
| 상위 개수 | `100` | 가져올 최대 행 수 |
| 열 제한 | 필요한 열만 선택 | 페이로드 축소 |

**SharePoint 필터 쿼리 문법 주의**

```
Title eq '홍길동'                       (문자열은 작은따옴표)
Amount gt 1000000                       (숫자는 따옴표 없음)
Created ge '2026-01-01T00:00:00Z'       (날짜는 ISO 8601 + 작은따옴표)
Status/Value eq '승인'                  (선택 열은 /Value)
Author/EMail eq 'a@contoso.com'         (사용자 열은 /EMail — 대소문자 주의)
startswith(Title, '[긴급]')
```

- 값에 작은따옴표가 있으면 두 번 써서 이스케이프합니다: `'O''Brien'`
- 표현식으로 값을 넣을 때 따옴표를 빼먹는 실수가 잦습니다:
  `Status eq '@{variables("대상상태")}'` ← 작은따옴표 필수

> **목록 보기 임계값(5,000)**: 인덱스가 없는 열로 필터하면 목록이 5,000행을 넘는 순간 실패합니다.
> 필터·정렬에 쓰는 열은 SharePoint 목록 설정에서 **인덱싱**해 두세요.

## 3.5 페이지 매김(Pagination)

`항목 가져오기` 같은 액션은 기본적으로 일부만 가져옵니다(SharePoint는 기본 100건).

액션 **설정 → 페이지 매김 → 켬 → 임계값** 을 지정하면 커넥터가 알아서 여러 페이지를 이어 가져옵니다.

- 임계값은 커넥터마다 상한이 다릅니다.
- 임계값을 크게 잡을수록 실행 시간과 메모리 사용이 늘어납니다.
- 수만 건을 다뤄야 한다면 애초에 **날짜 범위로 나눠 여러 번 실행**하는 설계가 안전합니다.

## 3.6 HTTP 액션 (프리미엄)

커넥터가 없는 REST API를 직접 호출합니다.

```
방법: POST
URI:  https://api.example.com/v1/orders
헤더:
  Content-Type: application/json
  Authorization: Bearer @{variables('accessToken')}
본문:
  {
    "orderId": @{triggerBody()?['orderId']},
    "note": @{json(concat('"', replace(triggerBody()?['note'], '"', '\"'), '"'))}
  }
```

**본문에 값을 끼워 넣을 때의 함정**

- 본문 편집기에 JSON을 직접 쓰면 문자열 값의 따옴표·이스케이프를 직접 책임져야 합니다.
- 값에 큰따옴표·줄바꿈·역슬래시가 들어오면 JSON이 깨집니다.
- **더 안전한 방법**: `작성` 액션에서 객체를 만들고 그 출력을 본문에 통째로 넣습니다.

```
작성 (이름: 요청_본문)
입력:
{
  "orderId": @{triggerBody()?['orderId']},
  "note": @{triggerBody()?['note']}
}
```

여전히 이스케이프 문제가 있다면 `setProperty()`로 조립하세요.

```
@setProperty(
  setProperty(json('{}'), 'orderId', triggerBody()?['orderId']),
  'note', triggerBody()?['note']
)
```

이 방식은 엔진이 직렬화를 처리하므로 **어떤 문자가 와도 깨지지 않습니다.**

### 인증

- **원시(Raw)**: 헤더에 토큰 직접 지정
- **Active Directory OAuth**: 앱 등록 후 클라이언트 자격 증명
- **관리 ID**: Azure 리소스 호출 시

> 토큰이나 API 키를 액션에 하드코딩하지 마세요. **환경 변수**나 Azure Key Vault 커넥터를 쓰세요(8장).

## 3.7 응답(Response) 액션

HTTP 트리거 플로우에서 호출자에게 결과를 돌려줍니다.

```
상태 코드: 200
헤더: { "Content-Type": "application/json" }
본문:
{
  "ok": true,
  "processed": @{length(body('배열_필터링'))}
}
```

- 응답 액션까지 도달하지 못하면 호출자는 타임아웃 또는 `502`를 받습니다.
- 그래서 **오류 경로에도 응답 액션을 두어야** 합니다(6장 try/catch 패턴).
- 응답은 약 120초 안에 나가야 합니다. 오래 걸리는 작업은 즉시 `202`를 주고 비동기로 처리하세요.
